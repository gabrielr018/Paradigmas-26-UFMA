## 📝 Sobre o programa

O programa desenvolvido visa simular um sistema de vendas de bebidas para maiores de 18 anos, permitindo assim praticar a aplicação da lógica de programação para tomada de decisões.

O objetivo principal do algoritmo é utilizar estruturas condicionais e operadores lógicos para validar duas regras de negócio primordiais antes de emitir um comprovante de compra: a **maioridade legal** (18 anos) e o **saldo disponível** do cliente.

## ⚙️ Funcionalidades

O script simula o fluxo de um caixa com as seguintes características:
- **Coleta de informações dos Clientes:** Solicita o nome do comprador.
- **Entrada Financeira:** Solicita o saldo disponível para a compra.
- **Menu Interativo:** Exibe um catálogo com as opções de cervejas e seus respectivos valores.
- **Tomada de Decisão:** Calcula o valor total (preço × quantidade) e exibe o resultado final com base em 4 caminhos lógicos:
  1. Cliente possui idade e saldo (Compra Aprovada).
  2. Cliente possui idade, mas não possui saldo (Compra Negada).
  3. Cliente não possui idade, mas possui saldo (Compra Negada).
  4. Cliente não possui idade nem saldo (Compra Negada).
